# Funngro — 2 Page Website Design

This is an original responsive concept built for the Funngro evaluation project.

## Pages
- `index.html` — Home / landing page
- `teen.html` — For Teens / Teenlancer page

## SEO
Both pages include:
- unique `<title>`
- meta description
- keywords
- semantic headings
- responsive layout
- internal navigation
- accessible text links

## Run locally
Open `index.html` in a browser.

## Free deployment
### GitHub Pages
1. Create a new GitHub repository, e.g. `funngro-website`.
2. Upload all four files.
3. Go to **Settings → Pages**.
4. Select **Deploy from a branch → main → /root**.
5. Save and wait for the Pages URL.
6. Submit that URL in the Funngro project remark.

### Netlify
Create a free site and drag the project folder into Netlify's deployment area.
